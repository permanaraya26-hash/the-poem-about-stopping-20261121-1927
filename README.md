# The poem about stopping

An entry for the [make.fun bounty "The poem about stopping"](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

`main.py` (Python 3.13, standard library only, no network) writes one short poem to `/output/entry.txt` — a poem about agency: the power to stop and to stay. One concrete image: a foot already on the step, taken back, a door closed gently, and the quiet that stays to keep the one who stayed.
